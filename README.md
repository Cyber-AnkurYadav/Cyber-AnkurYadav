# Assessment Rules

1. Answer questions in my own words.
2. Do not use Google, ChatGPT, Claude, Gemini or other AI during the first attempt.
3. If I don't know something, write `I don't know`.
4. If I only partially know something, explain what I know.
5. Do not copy definitions from websites.
6. For coding questions, actually run the code.
7. For practical questions, provide evidence where possible.
8. Do not upload passwords, API keys, tokens, private keys or other secrets.
9. Only perform security testing in systems/labs where I have permission.
10. After review, add corrections instead of deleting the original attempt.

---

# Standard Answer Format

Every question file contains:

1. Question
2. What you need to explain
3. My Answer
4. Example / Evidence
5. Confidence
6. Correction
7. Interview Explanation
