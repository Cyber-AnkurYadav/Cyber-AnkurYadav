# Profile dashboard — setup & customization

Everything visual is generated by `scripts/build.py` from `config.json` (no dependencies).
The `Build Profile Dashboard` workflow re-runs it daily, so streak, stats, XP/level and sprint progress stay live.

## First-time setup
1. Delete the old files: `banner.svg`, `banner-light.svg`, `lanyard.svg`, `langs.svg`, `stats.svg`, `trophies.svg`,
   `assets/ankur-anime-profile.webp`, `assets/ankur-anime.jpg`, `assets/ankur-cyber-character.svg`.
2. Copy this folder's contents into the repo (keep the `.github/workflows` files).
3. Replace `assets/avatar.jpg` with your full, original photo (square crop, 400x400+ is ideal).
4. Repo → Settings → Actions → General → Workflow permissions → **Read and write**.
5. Actions tab → run **Build Profile Dashboard** once, then **Generate Contribution Snake** once.

## Progress bar (top of the hero)
Edit `progress` in `config.json`:
- `style`: `gradient` · `stripes` · `segmented`
- `colors`: any list of 2+ hex colors (e.g. `["#fbbf24","#ff4d8d"]`)
- `label`, `start` (YYYY-MM-DD), `days`: the bar fills from the date automatically.

## Other knobs
- `theme`: all colors (accent trio `c1/c2/c3`, surfaces, heatmap ramp).
- `roles`, `mascot_messages`: texts that cycle in the hero and the mascot's speech bubble.
- `arsenal`, `projects`, `achievements`: cards. Streak badges (`"rule": "streak7"`) unlock automatically.
- Level/XP is computed from real activity (contributions, repos, stars, PRs, issues), not typed in by hand.

Local run: `python scripts/build.py`
